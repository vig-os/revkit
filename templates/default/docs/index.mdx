## What this is

This is a docs repository that consumes the revkit flake:

- **Content** lives here as MDX. Only registered components are allowed
  (ADR-0002); the CLI's authoring guards refuse hand-rolled HTML/CSS/JS.
- **Vocabulary** is defined once in `vocab/terms.yaml`; `<Term id>`
  references resolve there.
- **`revkit check`** enforces the five authoring guards from ADR-0005:
  component registry, no hand-rolled UI, vocabulary, links, plot
  structure — plus the vendored-code contract from ADR-0022.
- **`revkit build`** (M5 part 2) renders this `docs/` tree through
  revkit's packaged Astro/Starlight site with its pinned node_modules,
  writing HTML to `.revkit/dist/`. No `bunx`, no `npx`, no registry
  fetch — everything comes from the flake input.
- **`revkit serve`** boots the local review daemon on `127.0.0.1`
  and mounts the rail (ADR-0006, ADR-0007, ADR-0013) on every rendered
  page. When `.revkit/dist/` is missing it runs `revkit build` first.

## Three commands

```bash
direnv allow       # or: nix develop
revkit check       # run the authoring guards
revkit build       # render docs/ into .revkit/dist/
revkit serve       # boot the review daemon
```
