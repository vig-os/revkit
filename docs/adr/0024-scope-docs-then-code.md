# ADR-0024: Scope: docs first, code diffs in M8

- Status: Accepted
- Date: 2026-09-29
- Design: [DESIGN-0001](../designs/DESIGN-0001-revkit-architecture.md)

## Context

Owner decided to plan code-diff review rather than exclude it.

## Decision

- v1 (M1–M7) renders **documents only**; code review stays on GitHub.
- **M8** adds source diffs with the same comment rail, anchors and GitHub review mapping (story B7, #15).

## Consequences

Stories: B7.
