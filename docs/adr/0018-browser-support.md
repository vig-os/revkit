# ADR-0018: Browser support

- Status: Accepted
- Date: 2026-09-29
- Design: [DESIGN-0001](../designs/DESIGN-0001-revkit-architecture.md)

## Context

The review surface targets phone, tablet and desktop.

## Decision

- **Evergreen, last two versions** of Chrome/Edge, Firefox and Safari, including iOS/iPadOS Safari.
- Tested with Playwright Chromium and WebKit (Firefox added if a regression shows up).

## Consequences

Stories: C6, E1.
