# ADR-0019: UI languages: English v1, i18n-ready

- Status: Accepted
- Date: 2026-09-29
- Stories: C6
- Design: [DESIGN-0001](../designs/DESIGN-0001-revkit-architecture.md)

## Context

Starlight ships an i18n layer; the owner wants English first.

## Decision

- UI strings go through Starlight's i18n layer from day one; **only English ships** in v1.
- Document content language is the author's choice and out of scope here.

## Consequences

See Decision.
