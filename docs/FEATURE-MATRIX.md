# Feature matrix

decide it, and where it is tracked. The guardrails `adr-matrix` gate fails a commit when an **Accepted** ADR is not
cited here; the ADR index lives in [`adr/README.md`](adr/README.md). Feature PRs update the affected status rows;
`adr-matrix` validates traceability, not delivery state.
